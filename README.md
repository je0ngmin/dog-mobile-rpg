# Dog Mobile RPG — Core Prototype

Godot 4.7 / GDScript로 만든 자동 원정 수직 슬라이스입니다.

## 실행

Godot에서 프로젝트를 열고 `F6` 또는 `F5`를 누릅니다.

개발 중 저장 데이터를 초기화하려면 다음 명령을 사용합니다.

```sh
godot --headless --path . --script res://scripts/dev/reset_save.gd
```

현재 구현:

- 1인으로 시작해 골드로 최대 3인까지 확장하는 강아지 원정대
- 캐릭터별 골드 강화와 핵심 속성 누적 보너스 표시
- 스테이지 기반 지수 골드 경제와 만·억·조·경 단위 표시
- 처치 위치에서 골드 UI로 흡수되는 코인 드롭 연출
- 원정대의 자동 이동, 자동 타깃, 자동 공격
- 역할별 능력치와 자동 스킬
- 적 웨이브, 처치 게이지, 보스, 다음 스테이지 해금
- 보스 격파 시 생존 캐릭터 완전 회복
- 전멸 후 골드로 전원 부활 및 현재 스테이지 재시작
- 경험치/계정 레벨, 골드/식량/고철/기계 부품
- JSON 저장 및 최대 8시간 오프라인 보상
- 에셋 없이 실행 가능한 프리비주얼 UI

## 구조

- `scripts/components`: 재사용 가능한 체력/공격/자동 스킬
- `scripts/actors`: 강아지와 적의 이동 및 컴포넌트 조율
- `scripts/systems`: 스테이지 진행과 스폰
- `scripts/core`: 저장 가능한 영속 게임 상태
- `scripts/world`: 전투 배경과 이펙트 프리비주얼

장비, 마을, 스킬 데이터는 다음 단계에서 `Resource` 기반 정의 파일로 추가하고
현재 `GameState.add_loot()`와 레벨 신호에 연결할 수 있습니다.
